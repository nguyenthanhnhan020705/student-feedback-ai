# Notebook theo chủ sở hữu

| File | Người viết | Nội dung cần hoàn thiện |
| --- | --- | --- |
| `01_eda.ipynb` | Data | Nguồn, split, kiểm tra dữ liệu và EDA |
| `02_sentiment.ipynb` | Sentiment | Thí nghiệm cảm xúc và kết quả thật |
| `03_topic.ipynb` | Topic | Thí nghiệm chủ đề và kết quả thật |

Hiện cả ba là notebook rỗng hợp lệ, chưa có cell/output hoặc kết quả. Dùng module Python của chính phần mình để tránh hai phiên bản thuật toán. Không đưa dữ liệu riêng tư hoặc kết quả giả vào notebook. Sentiment và Topic có thể chuẩn bị notebook/tests song song trước khi nhận Data thật.
