# CT3 — Word and character TF-IDF

User approved the proposed word + character direction and requested implementation
and a percentage comparison with the original system. This is an offline research
experiment; deployment is a separate decision under the existing CT1 protocol.

## Design

Keep the existing train/validation splits and normalizer. Fit a FeatureUnion of
the original word TF-IDF and char_wb TF-IDF (3–5 characters, min_df=2,
sublinear_tf=True, lowercase=False, preprocessor=normalize_text, L2 per branch).
Use LinearSVC C=1, dual=auto, max_iter=5000, random_state=42. Word weight is 1;
character weights are 0.5, 1 and 2. Try each with no class weighting and with
CT2's per-task selected weights (derived from train counts). These six paired
variants / twelve fits are fixed before inspecting scores. No broad tuning.

Alternatives: word-only is the CT1/CT2 control; character-only would discard
the explicit word baseline. Combined features preserve both and match the user's
choice. The exact ranges/weights above are implementation choices, not a claim
that the user specified them.

Rank each task including original baseline, CT2 selected and all CT3 variants by
validation Macro F1, then Accuracy within fixed global 1e-6 bands; ties prefer
baseline then CT2 then declared CT3 order. Known cases never affect selection.
Save the combined research selection and also rank the CT3-only variants so the
effect of the new representation is visible even if a control wins.

Report original/CT2/CT3 Accuracy, Macro F1, per-class precision/recall/F1 and joint
accuracy (both labels correct), percentage-point differences and relative change,
improved/regressed IDs and the 39 provisional known cases with null denominators.
No new test inference and no independent generalization claim. Character features
may help spelling variation; this is a hypothesis, not a promised result.

## Preservation and replay

Reuse feature/integration-p0 and locked venv. Preserve all CT1/CT2 inputs and
serving artifacts. Output only below .local-tools/ct3-word-char/<fresh-run>.
Refuse existing/overlapping outputs. Bind config, source/runtime, CT1/CT2 evidence,
all payloads and saved predictions by hashes. Replay in a fresh process without
fit, recomputing weights/metrics/ranking and checking effective pipeline params,
train-only word and character vocabularies/IDF, metadata and ModelService readiness.
Do not alter API/UI, preprocessing, original notebooks or models/. No new
dependencies, CT4/CT5/Phase 6, commit/push/merge/publication.
