# Đặc tả dùng chung — leader chốt Phase 0

**Trạng thái:** Các file dưới đây là mẫu để leader hoàn thiện, chưa phải đặc tả đã phê duyệt.

- [MVP](mvp.md): phạm vi, người dùng, luồng và nghiệm thu.
- [Hợp đồng API](api-contract.md): request/response/lỗi, giới hạn và health.
- [Hợp đồng Data và model](data-contract.md): loader, nhãn, split, pipeline/metadata.
- [Quyết định](../decisions.md): phiên bản, môi trường, trạng thái chốt và phần chưa chặn P0.

Leader ghi giá trị cụ thể, phiên bản/ngày chốt và thông báo cho cả năm người trước khi triển khai các giao diện kết nối. Dùng [checklist](../phase-0-leader-checklist.md). Khi đã chốt, mỗi người có thể làm phần độc lập theo [phân công song song](../team-assignments.md); chỉ chờ đầu ra thật ở mốc bàn giao tương ứng.
