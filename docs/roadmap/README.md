# Lộ trình hiện hành

Sử dụng [kế hoạch sáu phase đã duyệt](../superpowers/plans/2026-10-30-course-demo-completion.md). Phase 1–5 đã hoàn thành theo phạm vi từng phase. Phase 4 có 42 tests Frontend đạt trên Chrome/Edge và toàn suite 224 passed, không skip; xem [bằng chứng](../../reports/evidence/phase-4/README.md). Lỗi nhỏ Backend về tên trường lỗi cho khóa JSON Unicode bất thường vẫn được ghi rõ ở Phase 3. Phase 5 đã chạy lại đủ 224 tests, diễn tập restart/offline guard và đóng gói local; xem [bàn giao](../../DEMO.md). Bước tiếp theo là Phase 6 báo cáo/slide khi được yêu cầu; chưa nghiệm thu toàn sản phẩm.

1. Chốt bản tích hợp và môi trường.
2. Xác minh Data và hai model.
3. Hoàn thiện Backend.
4. Hoàn thiện Frontend.
5. Kiểm thử tổng thể và đóng gói demo.
6. Báo cáo, slide và bàn giao.

[Phase 0 v1.0](phase-0-specification.md) vẫn là hợp đồng đã duyệt. Các roadmap triển khai cũ được lưu ở `../archive/roadmap/`; không dùng để đánh giá tiến độ hiện tại. P1 chưa triển khai, các placeholder P1 rỗng đã được dọn.
